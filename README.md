
# JobTrack Pro — Job Application Tracker

A job application management web application built using Python, Flask, SQLite, HTML, and CSS.


## Live Demo

🚀 **Try JobTrack Pro Online:**

https://shumaila.pythonanywhere.com/

A Flask-based job application tracker with dashboard statistics, application management, search, filters, and follow-up reminders.


## Features

- Add new job applications
- View, edit, and delete applications
- Search applications by company
- Filter applications by status
- Dashboard statistics
- Application progress timeline
- Follow-up reminder system
- Due today, overdue, and upcoming follow-ups
- Job details including salary, location, notes, and dates
- Responsive dashboard interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
- Git and GitHub

## Installation

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Open the project folder:

   cd Job-Application-Tracker

3. Create a virtual environment:

   python -m venv .venv

4. Activate the virtual environment on Windows:

   .venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Initialize the database:

   python database.py

7. Start the Flask application:

   python app.py

8. Open in your browser:

   http://127.0.0.1:5000

## Project Purpose

JobTrack Pro helps users organize job applications, monitor application progress, and track follow-up reminders in one dashboard.
